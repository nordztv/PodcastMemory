# Evening run procedure: the morning call

**Two runs make each day (Scott's choice, 13 Nov 2026).** This evening run makes the **morning call** (parts 01 to 06) for tomorrow and plans her day. The **afternoon run** (`show/afternoon_run.md`, about 1:45pm on the call day) makes the afternoon call (parts 07 to 11) with the day's real news, weather and Scott's morning answers. Wherever this file mentions parts 07 to 11, the chat, the Friday features or the weekly review, that work now belongs to the afternoon run; this run only prepares for it in `EP/day_plan.md`. A safety-net run at about 4:50am makes the morning call if this run failed (`show/safety_run.md`).

Followed by the scheduled task on Sunday to Thursday nights, each time for the next morning's call (Monday to Friday). Weekend evenings have their own single call (`show/weekend_run.md`). The run starts about 8:30pm Sydney time (Scott's choice, 28 October 2026; was 9:30pm), so the script should be pushed by about 9:15pm and the audio delivered by about 9:45pm; the morning call MUST be delivered before 6:00am. Work unattended: never ask questions, make sensible choices, and note any assumption in the delivery message. Check the Sydney time at the start and regularly (the current_time tool if present, otherwise `TZ=Australia/Sydney date`).

**Time budget (Sydney):** the run starts about 8:30pm the evening before. Aim to have the script committed and pushed by about 9:15pm, then render audio if the voice engine runs (about fifteen minutes for a 30 to 35 minute call). If it's past 5:40am and rendering isn't finished, join whatever sections are done and deliver those.

Let `DATE` = the date of the calls: the Sydney date of the coming morning (the run starts in the evening, so this is normally TOMORROW's Sydney date; only if a run starts after midnight is it today's), in YYYY-MM-DD. Use that date and its weekday for everything (the greeting, "Friday" rules, file paths, the answer page), `REPO` = the clone of nordztv/podcastmemory, `EP` = `REPO/archive/YYYY/MM/DATE`.

## The idea, in one paragraph

the day is **two live phone calls from Mizuki on the call day** (bible section 5, The two calls): about 8am from her flat over breakfast (parts 01 to 06: last night, this morning, the news she read before bed), and about 4pm from the shop's quiet hour (parts 07 to 11: today's lunch rush, tonight's plans). It has to sound like a real person who knows Scott (bible section 3, Sound like someone talking; section 6). Three tools keep the run honest: `python3 engine/preflight.py DATE` (the day's brief: special rules, where she is, the dice, due threads, variety), `python3 engine/check_script.py DATE am|pm|eve` (pronunciation plus the realism check for that call; fix every FIX line) and `python3 engine/ledger.py check` (her money adds up).
