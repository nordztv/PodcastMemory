Notes for the show from Scott's chats with Claude: questions he asked, things he liked or didn't, answers to the host's questions, storyline updates, feedback. Any Claude chat can add a line here (the "podcast note" skill does it); Scott can add lines himself too.

Format: `- YYYY-MM-DD | type (asked, liked, not interested, answer, storyline, feedback) | note`
